# JP Digital Solutions

Personal portfolio of **JP Digital Solutions** — Full Stack Development & Digital Solutions.

Built with vanilla HTML, CSS, and JavaScript.
No frameworks. Just clean, intentional code.

---

## Features

* Responsive design (mobile-first)
* Interactive hero with floating tech icons + wireframe connections
* Project showcase with image crossfade (hover / tap)
* Debug Squash playground (mini-game)
* Matrix Mode unlock (session-based)
* Contact form (Formspree)
* Smooth scrolling & micro-interactions

---

## Tech Stack

* HTML5
* CSS3 (Custom Properties, Grid, Flexbox)
* Vanilla JavaScript
* Formspree
* Netlify (Hosting)

## Getting Started

1. Clone or download the repository.
2. Open `index.html` directly in your browser.
3. Or run a local development server (recommended):

```bash
npx serve
```

---

## Configuration

All site content is controlled through `config.js`.

You can manage:

* Site information (name, email, location, tagline)
* Navigation links
* Floating tools
* Services
* Projects and optional hover images
* Design tokens

Edit `config.js` to update the site's content without needing to modify the HTML, CSS, or JavaScript files.

---

## Matrix Mode

Win the **Debug Squash** playground by fixing all 10 bugs to unlock Matrix Mode.

Matrix Mode is session-based and resets when the page is refreshed.

---

## Deployment

The website is deployed on **Netlify**.

To deploy, connect the repository to Netlify or drag and drop the project folder into Netlify.
